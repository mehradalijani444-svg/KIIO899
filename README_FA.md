# KIIO Panel Starter

قالب مستقل با تم مشکی و لینک پشتیبانی https://t.me/KIIOVPN.

## نصب با گوشی
1. فایل ZIP را استخراج کنید و محتویات پوشه `kiio-panel` را در یک مخزن جدید GitHub با نام `kiio-panel` آپلود کنید.
2. در Railway از GitHub repo یک سرویس بسازید.
3. در Settings → Networking دامنه تولید کنید. برنامه روی پورت 8080 اجرا می‌شود.
4. در Variables مقدار `ADMIN_PASSWORD` را روی یک رمز طولانی و قوی بگذارید و `TELEGRAM_URL` را برابر `https://t.me/KIIOVPN` قرار دهید.
5. برای حفظ داده‌ها Volume اضافه کنید و Mount Path را `/data` قرار دهید؛ سپس `DATA_DIR=/data` را در Variables بگذارید.
6. وارد `https://دامنه/admin` شوید.

## محدودیت مهم
این فایل یک starter مستقل است: ظاهر مشکی، صفحه ساب‌لینک و توکن‌های نمایشی دارد. هسته Xray، ساخت واقعی کانفیگ VLESS/VMess/Trojan، احراز هویت واقعی کاربران، شمارش حجم و تاریخ انقضا پیاده‌سازی نشده‌اند؛ لینک‌های ساخته‌شده فعلاً کانفیگ قابل اتصال نیستند. برای سرویس عملیاتی باید backend و هسته Xray جداگانه و امن اضافه شوند. این کد از صفر نوشته شده و کپی SuperJinX نیست.
